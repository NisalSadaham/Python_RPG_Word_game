# Python RPG Game 🎮

## About the Project

This is a simple RPG (Role-Playing Game) built with Python as a personal learning project. The main purpose of this project was to learn and practise **Object-Oriented Programming (OOP) in Python** by applying OOP concepts in a game environment.

Rather than learning only through theory, I wanted to gain practical experience by building a game and understanding how classes, objects, attributes, and methods work together.

## Learning Objectives

Through this project, I aimed to practise:

- **Classes and Objects** — representing game elements using Python classes and objects.
- **Attributes and Methods** — defining the properties and behaviours of game objects.
- **OOP Fundamentals** — applying object-oriented concepts to a practical project.
- **Problem-Solving** — using Python to implement game functionality.

## Technologies Used

- Python

## What I Learned

This project helped me develop a better understanding of Python's Object-Oriented Programming concepts through hands-on practice. It also gave me experience in organising code and applying programming fundamentals to build a game.
